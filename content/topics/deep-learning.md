Deep learning uses neural networks with many layers to learn hierarchical representations directly from raw data — pixels, waveforms, tokens.

## Core idea

Each layer transforms its input into a slightly more abstract representation. Early layers might detect edges in an image; deeper layers detect shapes, then objects.

- **Backpropagation** — how the network learns, by pushing error signal backward through layers.
- **Architectures** — CNNs (grids), RNNs/Transformers (sequences), GNNs (graphs).
- **Scale** — deep learning's big unlock has been that performance keeps improving with more data and compute.

## Why it matters

Deep learning is the engine behind [NLP](#/topic/nlp), [Computer Vision](#/topic/computer-vision), and [Generative AI](#/topic/generative-ai). Almost everything labeled "AI" today sits on top of it.
